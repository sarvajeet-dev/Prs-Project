QUICK START
================================================================================

1. ADD API KEYS (2 minutes):
   - Go to https://newsapi.org → Register → Copy key
   - Go to https://gnews.io → Register → Copy key
   - Add to .env.local:
     NEWSAPI_API_KEY=your_key
     GNEWS_API_KEY=your_key

2. RUN APP (1 minute):
   npm run dev

3. OPEN BROWSER:
   http://localhost:3000/prospects

4. CLICK "DISCOVER NEW PRs":
   Wait 30-60 seconds for results

5. VIEW PROSPECTS:
   See organization, announcement, fit score, contact info

6. GENERATE EMAIL:
   Click "Generate Email" button
   See personalized draft
   Copy or send directly
